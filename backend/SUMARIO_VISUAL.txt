## 🔄 Fluxo Completo

```
┌──────────────────────────────────────────────────────────────┐
│                    FRONTEND/CLIENTE                          │
└────────────────────┬─────────────────────────────────────────┘
                     │
                     │ Requisição
                     ▼
┌──────────────────────────────────────────────────────────────┐
│ CONTROLADOR (Try/Catch)                                      │
│  try {                                                       │
│    1. Validar entrada                                        │
│    2. Verificar duplicata                                    │
│    3. Criar instância (valida regras)                        │
│    4. Salvar no banco                                        │
│    5. Retornar sucesso                                       │
│  } catch (erro) {                                            │
│    - Tratar erro específico                                  │
│    - Retornar resposta estruturada                           │
│  }                                                           │
└────────────────────┬─────────────────────────────────────────┘
                     │
                     │ Resposta { sucesso, dados, erro }
                     ▼
┌──────────────────────────────────────────────────────────────┐
│                    FRONTEND/CLIENTE                          │
│                 if (sucesso) exibir dados                    │
│                 else exibir erro.mensagem                    │
└──────────────────────────────────────────────────────────────┘
```
